# Welbuk videos: English voice-over transcript with timing

Use this to record or generate other languages (Sarvam, Gemini, etc.). Each line has the moment it starts in the
picture and the time available ("slot") before the next line. Keep each recorded line within its slot; a line can
start up to about 0.8 s early if the previous line finishes early.

**Delivery files back to us:** one audio file per line, named by its ID (e.g. `tour-queue.wav`, `reel-r05.wav`),
or one file per film with ~1 s of silence between lines. `tools/lang-mix.py` fits them to the picture and builds
the audio track and captions for the player.

Column "Flyer version" is the same line updated with the client flyer points (ABHA, Care Scribe drafting
prescriptions and follow-ups, pharmacy alerts, multi-clinic reporting, closing "Doctors care for patients. Welbuk
cares for doctors." and the free demo). The current English video uses the "As in the English video" text.

Pronunciation: Welbuk = "Well-book". Keep product names in English: Welbuk Practice, Welbuk Care, Welbuk Health,
Care Scribe, Welbuk Cloud. Keep QR, ABHA, GST, SOAP as letters.
